# 24 GHz FMCW 链路预算

油充圆波导内 24 GHz FMCW 雷达的发射-波导-反射-接收-中频-数字处理
端到端预算。所有公式均可由 [link_budget.py](link_budget.py) 复现。

## 3. 波导损耗

### 3.1 介质损耗 (dielectric loss)

α_d [Np/m] = π · f · tan(δ) · n / c

| 油品 | tan δ @ 24 GHz | α_d (Np/m) | α_d (dB/m, 单程) |
|---|---|---|---|
| ISO HM46 矿物油 (洁净) | 0.0008 | 0.298 | 2.58 |
| ISO HV46 矿物油 (洁净) | 0.0010 | 0.372 | 3.23 |
| ISO HEES (酯基) | 0.0030 | 1.116 | 9.70 |
| 含 0.1 % 水乳化 | 0.0015 | 0.558 | 4.85 |
| 含 0.5 % 水乳化 | 0.0050 | 1.860 | 16.16 |

**设计基线**：HV46 洁净油，**单程 3.23 dB/m，往返 6.46 dB/m**。

### 3.2 导体损耗 (conductor loss)

钢制缸壁电导率 σ ≈ 1.4 × 10⁶ S/m，在 24 GHz 表面电阻：
R_s = √(π · f · µ₀ / σ) ≈ 0.082 Ω/sq

对 TM01 在圆波导 (半径 a) 中：
α_c [Np/m] = R_s / (η · a · √(1 − (f_c/f)²))

| 缸径 D | a (m) | f_c (GHz, 油中) | α_c (dB/m) |
|---|---|---|---|
| 25 mm | 0.0125 | 6.20 | 0.31 |
| 50 mm | 0.025 | 3.10 | 0.07 |
| 100 mm | 0.050 | 1.55 | 0.018 |
| 200 mm | 0.100 | 0.78 | 0.005 |

> 导体损耗在量级上**远小于**油的介质损耗，工程上可与介质损耗合并到
> 2.6–3.3 dB/m。

### 3.3 反射损耗 (piston end face)

钢活塞端面：理论全反射 → 实际 −0.5 dB（表面油膜、粗糙度）。

## 4. 往返总损耗 (Round-Trip Loss)

L_total = 2 · α · d + L_probe·2 + L_window·2 + L_piston

| d (mm) | L_dielectric (dB) | L_other (dB) | L_total (dB) |
|---|---|---|---|
| 50 | 0.32 | 5.5 | 5.8 |
| 100 | 0.65 | 5.5 | 6.2 |
| 250 | 1.62 | 5.5 | 7.1 |
| 500 | 3.23 | 5.5 | 8.7 |
| 1000 | 6.46 | 5.5 | 12.0 |
| 1500 | 9.69 | 5.5 | 15.2 |
| 2000 | 12.92 | 5.5 | 18.4 |

L_other = 探针 2×1.5 + 窗 2×1.0 + 活塞 0.5 = 5.5 dB（恒定项）。

## 5. 接收链

| 项目 | 值 |
|---|---|
| 接收端探针入射功率 P_r | +7.5 dBm − L_total |
| MMIC Rx 增益（LNA + Mixer 联合换算） | +10 dB |
| Mixer 变频损耗（已包含在 RF chain） | 已合并 |
| IF 信号在 ADC 前 | P_r + 10 dB |

| d (mm) | P_r (dBm) | IF (dBm) |
|---|---|---|
| 50 | +1.7 | +11.7 |
| 500 | −1.2 | +8.8 |
| 1000 | −4.5 | +5.5 |
| 2000 | −10.9 | −0.9 |

ADC 1 V_pp 满量程对应 +10 dBm（50 Ω）。需要**可编程 IF 衰减**保
留 0–20 dB 动态，避免饱和。

## 6. 噪声与信噪比

### 6.1 噪声源

| 项目 | 值 |
|---|---|
| kT₀ @ 300 K | −174 dBm/Hz |
| 系统噪声系数 NF (MMIC + IF) | 12 dB |
| FMCW IF 带宽（决定于 d_max） | 25 kHz |
| FFT 点数 N | 1024 |
| FFT 频率分辨率 Δf | 1/T_chirp = 4 kHz |

### 6.2 中频频率与带宽

f_b = 2 · B · d · n / (c · T_chirp)

| d (mm) | f_b (kHz) |
|---|---|
| 50 | 0.49 |
| 500 | 4.94 |
| 1000 | 9.87 |
| 2000 | 19.74 |

为容纳 d_max=2 m，IF 抗混叠滤波器 LPF 截止 25 kHz，ADC 采样 100
kSps 已足够，**实际取 1 MSps** 留 phase noise 与 chirp 复位的余量。

### 6.3 SNR

| d (mm) | IF (dBm) | Noise floor (dBm, in Δf bin) | SNR (dB) |
|---|---|---|---|
| 50 | +11.7 | −126 | 138 |
| 500 | +8.8 | −126 | 135 |
| 1000 | +5.5 | −126 | 132 |
| 2000 | −0.9 | −126 | 125 |

实际系统因相位噪声、chirp 非线性、量化噪声、多模等因素，**有效
SNR 限制在 60–90 dB**。即使如此，仍远超亚毫米精度需要的 50 dB。

## 7. 距离分辨率与精度

### 7.1 粗距离分辨率 (FFT 主峰)

Δd_coarse = c / (2 · B · n) = 3·10⁸ / (2·2.5·10⁸·1.48) = **0.405 m**

### 7.2 亚 bin 精度 (相位估计)

理论 CRLB (Cramér-Rao 下界)：
σ_d ≈ c · n / (4π · f_c · √(2·SNR_lin))

| SNR (dB) | σ_d (µm) |
|---|---|
| 50 | 1.6 |
| 60 | 0.5 |
| 70 | 0.16 |
| 80 | 0.05 |

实际算法 + 硬件限制：**σ_d ≈ 50–200 µm**，与 IRM 实测一致。

### 7.3 误差预算 (合成)

| 误差源 | 1σ (µm) |
|---|---|
| 量化 + 噪声 (CRLB @ 60 dB) | 50 |
| Chirp 非线性 | 30 |
| 油 ε_r 不确定度 (温补后) | 80 |
| 承压窗反射残差 | 40 |
| 机械稳定性 (热膨胀) | 30 |
| **RSS** | **~115 µm** |

满足 REQ-FN-003 (±200 µm) 的 ±0.05 % FS 指标。

## 8. 动态范围与窗反射

承压窗反射 ≈ −15 dB (设计窗的反射目标)：
- 反射信号 P_window = +10 − 1.5 − 15 − 1.5 − 10 = −18 dBm
- 与 2 m 处活塞回波相当，但 f_b 接近 0
- **必须在出厂用空缸 / 无目标状态录窗反射模板，在线扣除**

## 9. 链路预算总结一句话

往返链路总损耗 ≤ 19 dB；SNR 全程 > 100 dB；瓶颈不在功率而在
**phase noise、chirp 线性度、多模激励**。功放/低噪放需求很轻，可
以放心使用集成度高的 BGT24MTR12，无需外加 PA/LNA。
