# 油充圆波导模式分析

液压缸缸筒在 24/77 GHz 工作时是一段**充油的良导体圆波导**。本节
分析模式结构、截止频率、多模问题、群速色散、以及对算法的影响。

## 1. 圆波导主要参数

- 半径 a = D/2
- 填充介质 (液压油)：ε_r = 2.2, n = 1.48, tan δ ≈ 10⁻³
- 壁电导率 σ ≈ 1.4 × 10⁶ S/m (合金钢)

### 1.1 模式截止频率

对 TE_nm 和 TM_nm，截止波数 k_c = p / a：

| 模式 | p (Bessel 根) | 备注 |
|---|---|---|
| **TE11** | p'_11 = 1.841 | 主模 (TEM-like 极化) |
| TM01 | p_01 = 2.405 | 圆对称，**首选激励模式** |
| TE21 | p'_21 = 3.054 | |
| TE01 / TM11 | 3.832 (简并) | TE01 工业可用低损耗模 |
| TE31 | 4.201 | |
| TM21 | 5.136 | |
| TE41 | 5.318 | |
| TE12 | 5.331 | |
| TM02 | 5.520 | |

截止频率：
f_c = p · c / (2π · a · n)

| 缸径 D (mm) | f_c TE11 (GHz) | f_c TM01 (GHz) | f_c TM02 (GHz) |
|---|---|---|---|
| 25 | 4.74 | 6.20 | 14.21 |
| 50 | 2.37 | 3.10 | 7.11 |
| 80 | 1.48 | 1.94 | 4.44 |
| 100 | 1.19 | 1.55 | 3.55 |
| 150 | 0.79 | 1.03 | 2.37 |
| 200 | 0.59 | 0.78 | 1.78 |

## 2. 多模数量评估

在工作频率 f 下，能传播 (kc < k) 的模式数量近似 (Weyl 公式)：

N(f, a) ≈ (a · k)² / 4 = (π · a · f · n / c)²

| 缸径 D (mm) | 24 GHz 模式数 | 77 GHz 模式数 |
|---|---|---|
| 25 | ~22 | ~228 |
| 50 | ~86 | ~910 |
| 80 | ~220 | ~2330 |
| 100 | ~345 | ~3640 |
| 150 | ~775 | ~8190 |
| 200 | ~1380 | ~14560 |

> **解读**：D=25mm 在 24 GHz 已有 ~20 个传播模，D=200mm 上千个。
> 任何被探针弱激励的模式都会成为多径回波，污染主峰。
> 这是 IRM 类传感器最核心的工程难题。

## 3. 工程对策

### 3.1 模式优选：TM01

| 维度 | TE11 | **TM01** |
|---|---|---|
| 极化 | 线极化 | 旋转对称 |
| 端面探针耦合 | 需偏置/正交结构 | 同轴探针轴向自然激励 |
| 与活塞反射对称性 | 反射部分极化变换 | 反射保持 TM01 |
| 损耗 | 略低 | 中等 |
| 工业雷达常用 | 是 | **是 (IRM 业界主流)** |

**结论**：本设计采用 **TM01 模式**为工作模式。理由：
1. 圆波导端面同轴探针**自然激励 TM01**
2. 旋转对称性使活塞偏心、缸筒椭圆度对回波影响最小
3. 在 24/77 GHz 下损耗与 TE11 相当
4. Ayhan 等已发表的 IRM 工作均采用 TM01

### 3.2 探针对模式的选择性激励

- **轴向同轴探针**（在端盖中央，指向缸内）激励：
  - 主要：TM01 (E_z 在中心最大)
  - 次要：TM02, TM03 (在 ε_r·a 较大时)
  - 不激励：TE_nm (E_z = 0)
- 探针长度 L_probe ≈ λ_oil/4 ≈ 2.1 mm @ 24 GHz
- 探针根部到背腔距离 ≈ λ_oil/4 (短路面位置)

### 3.3 高阶 TM 模抑制

干扰主要来自 TM02 (截止比 TM01 高 2.30 倍)：

| 缸径 | TM02 截止 | f/fc 比 |
|---|---|---|
| 25 mm | 14.2 GHz | 1.69 (传播!) |
| 50 mm | 7.1 GHz | 3.38 (传播) |
| 100 mm | 3.55 GHz | 6.76 (传播) |

24 GHz 下 TM02 在所有目标缸径均传播。**抑制手段**：
1. 探针几何优化使 TM01/TM02 激励比 > 20 dB
2. 算法上：TM02 群速与 TM01 不同，多目标 FFT 可分辨
3. 必要时加**模式滤波环**（在端盖处的 λ_g/4 阻抗扼流圈）

## 4. 群速与色散

每个传播模的轴向波数：
β = √(k² − k_c²)，其中 k = 2π·f·n/c

群速：
v_g = c / n · √(1 − (f_c/f)²)

| 模式 | f_c (GHz, D=50mm) | v_g @ 24 GHz (×10⁸ m/s) | 与 c/n 比 |
|---|---|---|---|
| TM01 | 3.10 | 2.005 | 0.9917 |
| TM02 | 7.11 | 1.931 | 0.9551 |
| TM03 | 11.2 | 1.785 | 0.8833 |

> **TM02 群速比 TM01 慢 3.7 %** — 对应 2 m 距离的延迟差约
> 75 mm。如果 TM02 激励 −20 dB 且未被算法剔除，会在 d+75mm 处
> 产生一个 −20 dB 的伪峰，对应位置误差约 0.05 mm/dB 影响。

**算法侧策略**：
- 多峰检测；按幅度排序
- 主峰 = 真距离（信号最强）
- 副峰若 ± 数十毫米 → 怀疑 TM02 多径，但仍以主峰为准
- 现场标定时记录主/副峰幅度比作为油品 + 缸径的指纹

## 5. 截止附近的色散加剧

只有当工作频率 ≫ f_c 时，模式接近 TEM。靠近截止则 v_g → 0，距离
计算失真。

设计准则：**保证 f / f_c (TM01) ≥ 4** → D 不应小于：

D_min = p_01 · c / (2π · 4 · f · n) = 2.405·c/(8π·f·n)

| 频段 | D_min (mm) |
|---|---|
| 24 GHz | 8.1 |
| 77 GHz | 2.5 |

我们的最小缸径 25 mm 在 24 GHz 下 f/fc = 5.1，安全。

## 6. 油-空气接口 (end-of-stroke 工况)

若活塞行至接近端盖、油柱长度短到 < 50 mm，需考虑：
- 探针近场区影响
- 窗反射主导回波
- TM01 入口耦合区还未"稳定"

**死区**：本设计死区目标 ≤ 30 mm。机械上要求活塞最近距离端盖
≥ 50 mm（缸体设计约定）。

## 7. 77 GHz 注意事项

| 项目 | 24 GHz | 77 GHz |
|---|---|---|
| α_d (dB/m) | 3.23 | ~10.4 (≈ f 比例) |
| 2 m 单程衰减 | 6.5 dB | **21 dB** |
| 模式数 (D=50) | 86 | 910 |
| 适用缸径 | ≤ 200 mm | **≤ 60 mm** |
| 行程上限 (SNR 充足) | 2 m | ~1 m |

77 GHz 系列产品的型号矩阵需限制缸径与行程，否则衰减不可接受。
