# 工程总方案 (Plan v2)

## 1. 系统定位

IRM 传感器是一个**非接触式、基于油充圆波导的 FMCW 雷达**液压缸活塞
位置测量装置。它替代传统的磁致伸缩传感器与活塞杆深孔编码方案：
- 不在活塞内嵌磁铁
- 不对活塞杆做 gun-drilling
- 整个装置安装在液压缸**端盖端**，可现场更换
- 缸筒本身作为圆形金属波导，液压油作为低损耗电介质填充

## 2. 双频段策略

| 频段 | 主用途 | 缸径覆盖 | MMIC |
|---|---|---|---|
| **24 GHz ISM** | 主力机型，量大面广 | 50 – 200 mm | Infineon BGT24MTR12 |
| **77 GHz Auto** | 小缸径 / 高精度衍生型 | 25 – 60 mm | TI AWR1243 |

两条线**共用基带板、电源板、接口板、外壳、固件框架**，差异只在 RF
子板和探针几何。开发节奏 24G 领先 4 个月，DVT 阶段合流。

## 4. 信号链 (FMCW @ 24 GHz)

```
chirp:  f(t) = f_min + (B/T)·t,   B = 250 MHz, T = 250 µs
      
              ┌─ Tx ─► 探针 ─► 波导 ─► 活塞端面
   PLL ─VCO──┤                                  │
              └─ LO ──┐         反射             │
                      ▼                          │
                     Mixer ◄────── Rx ◄─探针◄──┘
                      │
                  IF: f_b = 2·B·d·n_oil / (c·T)
                      │
                ADC → FFT → 粗距离 → 相位估计 → 精距离
```

## 5. 算法栈

1. **采样窗整形** Hann (减泄漏)
2. **1D FFT** N=1024 → 粗距离 bin
3. **Chirp-Z / 抛物线插值** → 亚 bin 频率
4. **相位估计** 多 chirp 间 IF 相位差分 → sub-mm 残差
5. **温度补偿** PT1000 → ε_r(T) → v_oil(T)
6. **油品自标定** 利用承压窗反射回波 (已知物理位置) 反推当前 ε_r
7. **Kalman 平滑** 状态 = [位置 速度]，过程噪声/观测噪声可在线学习
8. **多目标剔除** 承压窗反射、内置阻尼器反射等已知伪峰用模板减除

## 8. 现场标定流程 (出厂)

1. **干燥状态** — 无油，测承压窗反射作为零位基准
2. **充油** — 灌入标定油品，温度 25 °C
3. **全程扫描** — 用光栅尺定位活塞，每 10 mm 采样
4. **拟合** — 建立 d_radar ↔ d_real 的查表 + 二阶多项式残差
5. **温度循环** — 在 −40 / +25 / +85 / +105 °C 重复部分点，记录 ε_r(T)
6. **写入** — 标定参数烧入 EEPROM，IO-Link 可读不可写

## 9. 主要风险 (TOP 5)

| # | 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|---|
| 1 | 大缸径 (D≥150) 过模导致精度退化 | 中 | 高 | 探针模式过滤 + 多目标算法 + 限定产品系列 |
| 2 | 承压窗在 700 bar 疲劳泄漏 | 低 | 极高 | 双密封 + 玻璃-金属烧结 + 压力疲劳 10⁵ 循环 |
| 3 | 77 GHz 在大缸径完全失效 | 高 | 中 | 77G 系列只发布 ≤ 60 mm 缸径 |
| 4 | EMC (CISPR 11 Class A) 不过 | 中 | 高 | RF 屏蔽腔 + 早期预测试 |
| 5 | IO-Link 主站互通性 | 中 | 中 | 三家主站 (Siemens/Beckhoff/IFM) 互通验证 |

## 10. 与控制器的对接 (本仓库 src/)

`FB_CrossCoupledILC` 期望的输入：
- 位置反馈 `act_pos[i]` (REAL, mm) — IRM 提供
- 采样周期 `Ts` — 与 IRM 刷新率匹配 (1 kHz / 1 ms)
- 多缸 (i = 0..N-1) — 每缸一个 IRM 独立通道

接口约定见 [05-interface-board/modbus-register-map.md](../05-interface-board/modbus-register-map.md)。
