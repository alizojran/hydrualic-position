# System Requirements Specification (SRS)

文档版本 0.1 — 工程预冻结 (Pre-PDR)

## 1. 适用范围

本 SRS 描述 IRM 雷达式液压缸位置传感器的可验证需求。所有需求带有
唯一 ID (REQ-xxx)，用于贯穿 PDR/CDR/DVT 测试矩阵的可追溯。

## 2. 功能需求

### 2.1 位置测量

| ID | 需求 | 验证方式 |
|---|---|---|
| REQ-FN-001 | 测量活塞绝对位置，范围 0 – 2000 mm | 光栅尺台架对比 |
| REQ-FN-002 | 距离分辨率 ≤ 0.5 mm (rms) | 静态噪声测试 |
| REQ-FN-003 | 距离精度 ≤ ±0.2 mm 或 ±0.05 % FS (较大者) | 全程扫描 + 拟合残差 |
| REQ-FN-004 | 刷新率 ≥ 1 kHz，可配置 0.5/1/2 kHz | 总线时序分析 |
| REQ-FN-005 | 速度估计输出，分辨率 1 mm/s | 已知速度梯形剖面对比 |
| REQ-FN-006 | 上电后 100 ms 内输出有效位置 | 上电测试 |

### 2.2 适配缸体

| ID | 需求 | 验证方式 |
|---|---|---|
| REQ-FN-010 | 缸径适配 25 – 200 mm，型号系列化 | 产品型号矩阵 |
| REQ-FN-011 | 行程适配 50 – 2000 mm，同一硬件 | 全行程台架 |
| REQ-FN-012 | 缸盖端螺纹安装：G3/4 / M22×1.5 / M27×2 三规格 | 机械接口图 |
| REQ-FN-013 | 油品兼容：ISO HM/HV (矿物油)、HEES (酯基)、HFC (水乙二醇) | 多油品标定 |

### 2.3 通信接口

| ID | 需求 | 验证方式 |
|---|---|---|
| REQ-FN-020 | 模拟输出 0.5 – 4.5 V，线性 0–100 % 行程 | 万用表 + 已知行程 |
| REQ-FN-021 | IO-Link Class B，COM2 (38.4 kbps) / COM3 (230.4 kbps) | TMG IO-Link 测试仪 |
| REQ-FN-022 | RS-485 Modbus RTU，9600/19200/115200 bps 可选 | Modbus Poll 工具 |
| REQ-FN-023 | 接口可在出厂前通过 DIP/EEPROM 选择激活 | 配置流程 |
| REQ-FN-024 | 模拟 + 数字接口可同时输出 (相同数据) | 双通道同步采样 |

### 2.4 诊断与状态

| ID | 需求 | 验证方式 |
|---|---|---|
| REQ-FN-030 | 上报传感器内部温度 (±2 °C) | 与参考温度计对比 |
| REQ-FN-031 | 上报油液 ε_r 估计值 (在线) | 已知 ε_r 油样测试 |
| REQ-FN-032 | 上报信噪比、回波幅度，便于现场维护 | 故障注入测试 |
| REQ-FN-033 | 失效安全：信号丢失时输出 NAMUR 区 (<0.4 V 或 >4.6 V) | 断信号测试 |
