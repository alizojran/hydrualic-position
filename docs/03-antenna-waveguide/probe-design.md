# 同轴探针 + 模式启动器设计

把 50 Ω 同轴线上的 24 GHz 信号高效地耦合进 D=25–200 mm 的油充
圆波导的 **TM01 主工作模**，并在液压油 / 承压窗 / 探针金属界面间
保持 350 bar 持续 / 700 bar 峰值的密封。

## 1. 拓扑：端面同轴 + 阶梯阻抗匹配 + 承压窗

```
   PCB SMA 焊盘 ──同轴───┐
                         │
   ┌────────────────────┼──────────────────────┐ ← 端盖钢面 (波导导体壁)
   │                    │                       │
   │  RF 屏蔽腔          │  承压介质窗            │
   │  (50 Ω 同轴段)      │  (Φ4 mm 蓝宝石)        │
   │                    │   ε_r ≈ 9.4            │
   │            ┌──────┘                       │
   │  焊环 Kovar │   阻抗台阶 (1/4 λ 节)         │
   │            └──────┐                       │
   │                    │                       │
   │  内导体延伸 ──────►│●  ← 探针突出油腔       │ → 油充波导 (TM01)
   │                    │   L_probe ≈ 2.0 mm    │
   └────────────────────┴───────────────────────┘
                                              油 / 缸内
```

### 1.1 设计变量

| 变量 | 范围 | 初值 | 含义 |
|---|---|---|---|
| L_probe | 1.5 – 3.0 mm | 2.0 mm | 探针突出油腔长度 (≈ λ_oil/4) |
| D_probe | 0.5 – 1.0 mm | 0.6 mm | 探针直径 |
| L_back | 1.5 – 2.5 mm | 2.0 mm | 探针根部到 PCB 短路面距离 |
| D_window | 4.0 – 6.0 mm | 4.0 mm | 承压窗直径 |
| t_window | 1.0 – 4.1 mm | 2.027 mm | 蓝宝石厚度 = λ_sap/2 共振透射 |
| D_aper | 5.0 – 8.0 mm | 6.0 mm | 端盖开孔直径 |
| Z_step | 30 – 70 Ω | 50/30/50 Ω | 阻抗台阶 |

### 1.2 设计原则

1. **探针长度** 取 λ_oil/4 ≈ 8.38/4 = 2.10 mm（油中），形成共振耦合
2. **探针位置** 在端盖中心轴线上（最大化 TM01 耦合 = E_z 中心最强）
3. **背腔深度** ≈ λ_g/4，让背向波在短路面叠加增强前向激励
4. **承压窗厚度** = λ_sap/2 × N，N=1,2,...，共振透射
   - 蓝宝石 ε_r ≈ 9.4 → λ_sap = λ_0/√9.4 = 4.054 mm
   - **首选 t = 2.027 mm (N=1)** — 机械与电气折中最佳
   - 备选 t = 4.054 mm (N=2) — 抗压更优，材料成本上升
   - 不取 t = 1.013 mm (λ/4) — 那是反相点，反射极大化
5. **阻抗匹配** Q < 2 for 24.00 – 24.25 GHz 带宽

## 2. 蓝宝石窗的电磁影响

蓝宝石 (Al₂O₃) 单晶在 24 GHz 的电气参数：
- ε_r = 9.4 (c 轴) / 11.6 (a 轴) — 各向异性
- tan δ ≈ 1 × 10⁻⁴
- 击穿强度 ~ 30 kV/mm

电磁问题：
- ε_r 大幅突变 (1→9.4→2.2)，造成多重反射
- 若不做匹配，单层窗的反射可达 −5 dB（很差）
- 解决：**厚度精确匹配 λ_g_sap/2 的整数倍**，使窗"消失"
- 制造公差 ±20 µm → 反射 < −20 dB

替代材料对比：

| 材料 | ε_r | tan δ | 抗压强度 | 加工 | 单件成本 |
|---|---|---|---|---|---|
| **蓝宝石 (单晶)** | 9.4 | 1e-4 | 优 | 难 (硬度 9) | 高 |
| Al₂O₃ 99.5% 陶瓷 | 9.8 | 4e-4 | 优 | 难 | 中 |
| PEEK 工程塑料 | 3.2 | 3e-3 | 中 | 易 | 低 |
| 玻璃 (硼硅) | 4.6 | 1e-2 | 中 | 易 | 极低 |
| 石英 (熔融) | 3.78 | 1e-4 | 中 | 中 | 中 |

**初选**：蓝宝石（性能最佳）；**备选**：PEEK + 金属法兰承压（成本敏感型）。

## 3. 同轴-波导过渡的电气仿真目标

在 23.5 – 24.5 GHz 范围内：

| 指标 | 目标值 | 验证方法 |
|---|---|---|
| S11 | < −15 dB | HFSS 端口仿真 |
| TM01 模式纯度 | > 90 % | HFSS 模式分解 |
| TM02 抑制 | > 20 dB | 同上 |
| 插入损耗 | < 1.5 dB | S21 (探针→远端理想吸收) |
| 带宽 −10 dB | > 500 MHz | 频扫 |

## 4. 探针几何对 TM01/TM02 选择性激励

CST 仿真结果 (D=50 mm, 油中 ε_r=2.2)：

| L_probe | TM01 耦合 | TM02 耦合 | 比值 (dB) |
|---|---|---|---|
| 1.5 mm | −2.1 dB | −18.5 dB | 16.4 |
| **2.0 mm** | **−1.4 dB** | **−24.0 dB** | **22.6** |
| 2.5 mm | −1.7 dB | −19.0 dB | 17.3 |
| 3.0 mm | −2.5 dB | −16.0 dB | 13.5 |

> L_probe = 2.0 mm 时 TM01/TM02 比值最优，>22 dB 抑制 TM02 多径。

## 5. 不同缸径的探针适配

由于 TM01 在中心轴的 E_z 最大值与缸径无关 (J_0(0)=1)，理论上同一
探针几何在 D=25..200 mm 缸里都能激励 TM01。**实际差别**：

- D 大 → 探针对 TM02、TM03 等高阶 TM 模激励比例上升
- D 大 → 总传播模数增加，弱激励模累积成多径噪声

**对策**：
- D ≤ 100 mm 缸：单一探针几何 (L_probe=2.0 mm)
- D > 100 mm 缸：**增加端盖处的 λ_g/4 阻抗扼流圈**
  - 在探针周围环形开一圈 λ_g/4 深的同心圆槽
  - 对 TM02 引入 −10 dB 额外抑制
  - 对 TM01 几乎透明 (因为 TM01 在边缘 E_z 弱)

## 6. 承压窗机械方案

详细见 [04-pressure-window/pressure-window-design.md](../04-pressure-window/pressure-window-design.md)。
此处仅说明探针-窗的电气接口：

```
   PCB ──同轴SMD连接器（玻璃-金属密封, Pasternack PE91175）
        │
        │ 内导体 Φ0.6 mm 304SS
        │
        ▼
   ┌──────────────┐
   │  Kovar 焊环   │  ← 通过钎焊 (Au-Sn) 与蓝宝石窗烧结
   └─────┬────────┘
         │
       蓝宝石窗 t=2.027 mm (λ_sap/2)
         │
   ┌─────▼────────┐
   │  Kovar 焊环   │
   └──────────────┘
         │
       探针突出 2.0 mm
       (镀金 304SS 棒, Φ0.6 mm)
         │
         ▼
      油 / 缸内
```

整个组件作为**一体化卡盒**装入端盖，O-Ring 二次密封。

## 7. 制造容差

| 尺寸 | 公差 | 影响 |
|---|---|---|
| L_probe | ±50 µm | f_resonance 漂 30 MHz |
| t_window | ±20 µm | 反射 < −20 dB 达标 |
| 探针偏心 | ±200 µm | TM01 纯度退化 0.5 % |
| 焊环同心 | ±100 µm | 微弱反射 |
| 镀金厚度 | 2.0 ± 0.5 µm | 导电性能稳定 |

## 8. 77 GHz 衍生设计

| 参数 | 24 GHz | 77 GHz |
|---|---|---|
| λ_oil | 8.38 mm | 2.62 mm |
| L_probe | 2.0 mm | 0.65 mm |
| t_window (蓝宝石, λ_sap/2) | 2.027 mm | 0.640 mm |
| D_aper | 6.0 mm | 2.0 mm |
| 承压窗加工难度 | 中 | 高 (0.28 mm 蓝宝石易碎) |

77G 探针加工对精度要求 5× 严苛，需要专门工装。这是 77G 缸径上限
限制在 60 mm 的另一原因。
