# HFSS / CST 仿真计划

同轴探针 + 承压窗 + 油充圆波导一体化电磁仿真。本计划面向交付给
RF 仿真工程师独立执行，包含**模型结构、边界、激励、扫描矩阵、
输出指标、收敛判据**。

## 1. 工具选择

| 工具 | 用途 | 备注 |
|---|---|---|
| **Ansys HFSS 2023 R2+** | 主仿真 (有限元 / FEM) | 短波导段精度高 |
| **CST Studio Suite 2024** | 长波导段 + 时域 (TLM/FDTD) | 多模/瞬态分析 |
| Ansys Q3D | 同轴段寄生 | 探针根部寄生 |
| HFSS-IE / FEBI | 大尺度截断 | D > 100 mm 时减算力 |

## 2. 模型结构

```
   端口 P1 (Waveport, 50 Ω, SMA 同轴)
      │
   ── PCB SMD 同轴 ──
      │
   ── 玻璃-金属密封 (Kovar + 玻璃) ──
      │
   ── 同轴台阶段 (50 → 30 → 50 Ω) ──
      │
   ── Kovar 焊环 + 蓝宝石窗 ──
      │
   ── 探针突入油腔 (镀金 304SS 棒) ──
      │
   ── 油充圆波导 (D × L) ──
      │
   端口 P2 (Waveport, 模式 TM01 + TM02 + TM03 多模监测)
```

### 2.1 几何参数 (HFSS / CST 变量化)

```python
# 探针 / 窗
L_probe   = 2.0    # mm
D_probe   = 0.6    # mm
L_back    = 2.0    # mm 同轴背腔
D_window  = 4.0    # mm
t_window  = 2.027  # mm 蓝宝石 (λ_sap/2 共振厚度)
D_aper    = 6.0    # mm 端盖开孔
Z_step    = 30     # Ω 中间阻抗台阶
L_step    = 1.6    # mm λ/4 在中间介质

# 波导
D_cyl     = 50.0   # mm (扫描 25..200)
L_cyl     = 100.0  # mm (短截面，HFSS)；CST 时域可到 2000 mm
```

## 4. 激励与模式监测

P1 (输入)：
- Wave Port, 50 Ω 同轴 TEM 模

P2 (输出)：
- Wave Port, 多模 (Modal solution type)
- 监测前 10 个传播模式：TM01, TM02, TM03, TE11(两极化), TE21(两极化), TE01, TM11, TE31
- 输出每模的 S 参数 |S_{TM01,1}|², |S_{TM02,1}|² ...

## 5. 扫描矩阵

### 5.1 几何扫描 (DOE, 全因子)

| 变量 | 取值 | 点数 |
|---|---|---|
| L_probe | 1.5, 2.0, 2.5, 3.0 mm | 4 |
| D_probe | 0.5, 0.6, 0.8 mm | 3 |
| L_back | 1.5, 2.0, 2.5 mm | 3 |
| t_window | 1.95, 2.027, 2.10, 4.054 mm | 4 |
| D_cyl | 25, 50, 80, 100, 150, 200 mm | 6 |
| **小计** | 全因子 | **864** |

> 全因子代价过高。**改用 OFAT (一次一变) + 中心点**：
> - 阶段 1：固定 D=50, 扫 L_probe × t_window (16 点)
> - 阶段 2：固定最优探针/窗，扫 D (6 点)
> - 阶段 3：扫油 ε_r (3 点) × 频率 (3 点)
> - 总计约 ~50 次完整 3D 求解

### 5.2 频率扫描

- Range: 23.0 – 25.0 GHz
- Step: Discrete 0.025 GHz (81 点)
- Interpolating Sweep with max delta S = 0.001

### 5.3 油品 / 温度

| 油状态 | ε_r | tan δ |
|---|---|---|
| HV46 25 °C | 2.20 | 1e-3 |
| HV46 −40 °C | 2.30 | 6e-4 |
| HV46 +105 °C | 2.10 | 1.5e-3 |
| HM46 含 0.1 % 水 | 2.25 | 1.5e-3 |

## 6. 输出指标

每次仿真生成报表：

| 指标 | 单位 | 目标 |
|---|---|---|
| S11 @ 24.125 GHz | dB | < −15 |
| S11 max @ 23.5–24.5 | dB | < −10 |
| S_{TM01,P1} | dB | > −1.5 |
| Modal Purity = |S_TM01|² / Σ|S_mn|² | % | > 90 |
| S_{TM02,P1} / S_{TM01,P1} | dB | < −20 |
| Group delay 抖动 | ps | < 50 |

## 7. 长缸时域仿真 (CST)

HFSS 不适合 L_cyl=2000 mm + 多模长距离传播。改用 **CST Time
Domain (TLM 或 FIT)**：
- 模型：探针 + 窗 + 油波导 2 m + 活塞端面
- 激励：高斯调制脉冲 24.125 GHz ±150 MHz
- 输出：探针端时域回波，对比仿真延迟与 d·2·n/c 公式
- 验证：插入"假活塞"在 d = 0.5, 1.0, 1.5, 2.0 m，提取回波延迟

## 9. 收敛与网格

| 参数 | 建议 |
|---|---|
| HFSS Adaptive Δ S | 0.01 |
| 最大迭代次数 | 20 |
| 网格细化区域 | 探针周围 0.5 mm 内 → λ/20 |
| 远端波导 | λ/10 |
| 总自由度 | < 5M (单工作站可解) |

每模型预计 4–8 h on 32-core 工作站。

## 10. 验证 (Build vs Sim)

仿真 → 实物 → VNA 测量对比：

1. 制作探针 + 窗 + 钢管 (开口) 一体测试件
2. 一端 SMA，另一端开口 (自由空间，加吸波)
3. Anritsu MS46522B 矢量网络分析仪测 S11
4. 与仿真对比：S11 偏差 < ±2 dB @ 23.5–24.5 GHz 视为通过
5. 改装入油充测试缸，测远端短路件 (活塞模拟) 的距离延迟
