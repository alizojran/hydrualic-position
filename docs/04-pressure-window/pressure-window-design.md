# 承压介质窗设计

承压介质窗 (Pressure Window) 是 IRM 传感器的关键机械-电气-密封三
合一组件：电磁上**对 24 GHz / 77 GHz 微波透明**，机械上承受**油
侧 350 bar 持续 / 700 bar 峰值**且寿命 ≥ 10⁵ 压力循环，化学上耐
受液压油、酯基油、水基油以及微量水污染。

## 1. 功能与约束

| 约束 | 值 |
|---|---|
| 工作压力 | 350 bar (持续) / 700 bar (峰值) |
| 爆破压力 | ≥ 1750 bar |
| 压力疲劳 | 0 → 350 bar × 10⁵ 循环 |
| 工作温度 | −40 °C ~ +105 °C |
| RF 透射损耗 | ≤ 1.0 dB @ 24 GHz |
| RF 反射 | ≤ −20 dB |
| 化学兼容 | 矿物油 / 酯基 / HFC / 水含 |
| 寿命 | 10 年现场无更换 |
| 尺寸 | Φ < 8 mm, t ~ 1 mm 量级 |

## 2. 候选材料对比

| 材料 | ε_r | tan δ (24G) | 抗压 σ_c (MPa) | 弯曲 σ_b (MPa) | 加工 | 成本 (单件) |
|---|---|---|---|---|---|---|
| **蓝宝石 (Al₂O₃ 单晶)** | 9.4 | 1e-4 | 2100 | 700 | 难 (硬度 9) | $15 |
| Al₂O₃ 99.5 % 陶瓷 | 9.8 | 4e-4 | 2500 | 380 | 难 | $8 |
| ZrO₂ 氧化锆 | 30 | 1e-3 | 2000 | 900 | 中 | $20 |
| 熔融石英 (SiO₂) | 3.78 | 1e-4 | 1100 | 50 | 中 | $5 |
| 硼硅玻璃 | 4.6 | 1e-2 | 800 | 35 | 易 | $1 |
| PEEK (PEI 也类似) | 3.2 | 3e-3 | 100 | 170 | 易 | $0.5 |
| Si₃N₄ | 7.5 | 1e-3 | 3500 | 800 | 难 | $12 |

> **首选**：**蓝宝石**（电气最优 + 抗压充足 + 寿命极长）
> **备选 1**：99.5 % Al₂O₃ 陶瓷（性价比，介电略损）
> **备选 2**：PEEK + 金属法兰承压设计（成本敏感型，全塑料窗承载靠
> 金属环，PEEK 只做密封 + 介质透射）

## 3. 蓝宝石窗：电气厚度匹配

### 3.1 单层窗的反射

平面波垂直入射单层介质 (ε_r=9.4) 时，反射系数：
Γ = (r₁ + r₂·e^{-j2β·t}) / (1 + r₁·r₂·e^{-j2β·t})

其中 r₁ = (Z_oil−Z_sap)/(Z_oil+Z_sap), r₂ = (Z_sap−Z_oil)/...

β = 2π·f·√ε_sap / c

当 β·t = N·π (N=1,2,...) → 厚度 = N·λ_sap/2 → Γ = 0 (完美透射)

λ_sap = λ₀/√9.4 = 12.43/√9.4 = 4.054 mm

| N | t = N·λ/2 (mm) | 备注 |
|---|---|---|
| 1 | 2.027 | 太厚，机械上 ok，但加工成本上升 |
| 2 | 4.054 | 抗压更优 |
| 0.5 | 1.013 | 反相位 (反射极大化，不可) |

**实际选择**：**t = 2.027 mm (N=1, λ_sap/2)**

- 该厚度处反射理论为零，加工公差 ±20 µm 内反射 < −20 dB
- 机械上承载 350 bar 持续 + 700 bar 峰值 (FEA 见 §4.3)
- 若需更高抗压余量可上 t = 4.054 mm (N=2)，缺点是材料 + 加工成本上升
- 不取 λ/4 = 1.013 mm — 那是反相点，反射极大化

### 3.2 双层 + 阻抗匹配 (备选)

对 t < 1 mm 的薄窗方案，可用**双层介质** (蓝宝石 + 阻抗匹配层) 实
现宽带 −20 dB 反射：
- 主层：蓝宝石 t1，ε1=9.4
- 匹配层：石英 t2，ε2=3.78
- t1 = λ_sap/4, t2 = λ_qua/4, 频带宽 −20 dB ~ 40 % 中心频率

工程复杂度高于单层方案，**仅在多频段共用窗时启用**。

### 3.3 厚度公差

t = 2.027 ± 0.020 mm 加工标准。
- 公差 ±20 µm → 反射 < −22 dB（满足 −20 dB 指标）
- 公差 ±50 µm → 反射 −17 dB（不达标）

供应商要求：**激光干涉测厚 + 100 % 检验**。

## 4. 机械结构

### 4.1 总成示意

```
                                 ◄── 油压 350 bar
   ┌──────────────────────────────────────────┐
   │ 端盖 (40Cr 钢, 镀镍)                       │
   │   ┌────────────────────────────┐         │
   │   │   螺纹 / 法兰安装           │         │
   │   │                              │         │
   │   │  ┌──────────────────────┐   │         │
   │   │  │  Kovar 焊环 (外)     │   │         │
   │   │  │  ┌────────────────┐  │   │         │
   │   │  │  │ 蓝宝石窗        │   │         │
   │   │  │  │ Φ4 mm × 2.03 mm│  │   │         │
   │   │  │  └────────────────┘  │   │         │
   │   │  │  Kovar 焊环 (内, 焊钎)│   │         │
   │   │  └──────────────────────┘   │         │
   │   │                              │         │
   │   │       ★ O-Ring 二次密封      │         │
   │   │       (NBR 70 + PTFE 背环)   │         │
   │   └────────────────────────────┘         │
   └──────────────────────────────────────────┘
                                            探针 ↑ (从背面伸入)
```

### 4.2 蓝宝石-Kovar-钢的烧结堆栈

1. **蓝宝石窗 (Φ4 × 2.03 mm)**：c 轴沿厚度方向，端面 #80 镜面抛光
2. **Au-Sn 共晶钎焊 (80/20)**：蓝宝石两面金属化 (Ti/Pt/Au) 后与 Kovar
   焊环烧结，烧结温度 ~280 °C
3. **Kovar 焊环** (Φ外 7 / Φ内 4 / 厚 1.5 mm)：CTE 与蓝宝石匹配，
   避免热应力开裂
4. **激光焊接** Kovar 环到端盖钢体（环缝焊）
5. **O-Ring** 二次密封：在 Kovar-钢 配合面外侧
6. **背靠环 (PTFE)**：防止 O-Ring 高压外挤

### 4.3 压力级别 (FEA 估算)

蓝宝石窗作为简支圆板承受均布压力：

σ_max = (3 · p · r²) / (4 · t²) × (3 + ν) / 8

ν=0.27 (蓝宝石泊松比)
r = 2 mm (半径)
t = 2.027 mm

@ p = 350 bar (35 MPa):
σ_max = 3 × 35 × 4 / (4 × 4.11) × (3.27/8) = 25.6 × 0.41 = 10.5 MPa

@ p = 1750 bar (175 MPa) 爆破:
σ_max = 52.5 MPa

蓝宝石弯曲强度 ~700 MPa，安全余量 > 13×。**机械上极其安全**。

### 4.4 疲劳 (10⁵ 循环)

陶瓷材料疲劳寿命受应力强度因子控制。S-N 曲线在 50 % 弯曲强度水
平 (350 MPa) 下寿命 ~10⁷ 循环。本设计应力 10 MPa <<，**疲劳无忧**。

主要疲劳风险在**钎焊接头**：
- Au-Sn 钎缝在热循环下塑性应变
- 寿命预估 ~10⁶ 热循环 (−40 ↔ +105 °C)
- 等价 10 年使用 (每天 ~270 次循环) → 满足

## 5. PEEK 备选方案 (成本型)

如果项目降本，**PEEK 窗 + 金属网状承载** 方案：

```
   ┌─────────────────────────────┐
   │ PEEK 圆盘 (Φ8 × 1.5 mm)     │
   │ ε_r=3.2, λ_g/2=1.74 mm      │
   │                             │
   │ 后侧贴合不锈钢承压网格      │
   │ (开孔 Φ0.5 mm × 60% 占比)   │
   └─────────────────────────────┘
```

- PEEK 抗压 100 MPa，超过 350 bar 的 35 MPa → 板厚 1.5 mm 即可
- 但 700 bar (70 MPa) 接近极限，需要金属背靠网格
- RF 透射略损（金属网产生反射）→ 不超过 −12 dB 反射
- 成本约为蓝宝石方案 1/5
- **不推荐为主方案**，作为低端衍生

## 6. 工艺与测试

### 6.1 制造工艺流程

1. 蓝宝石加工：超声 + 激光，t 公差 ±20 µm
2. 蓝宝石金属化：磁控溅射 Ti(100 nm) + Pt(150 nm) + Au(300 nm)
3. Kovar 焊环：CNC 加工 → 镀 Ni 2 µm → 镀 Au 0.5 µm
4. 钎焊：Au-Sn 钎料 + 真空炉 280 °C × 10 min
5. 端盖：40Cr 钢，机加工 + 镀 Ni
6. 激光焊：Kovar 环到端盖，YAG 激光环缝
7. 100 % 氦检漏 (压差法, < 1×10⁻⁹ mbar·L/s)
8. 100 % 压力测试 (1.5× 工作压, 30 s)

### 6.2 验证测试

| 测试 | 标准 | 样本 | 通过判据 |
|---|---|---|---|
| 压力静载 | 700 bar × 1 h | 30 | 无泄漏 |
| 压力疲劳 | 0–350 bar × 10⁵ | 10 | 无泄漏 |
| 爆破 | 升压至破坏 | 5 | ≥ 1750 bar |
| 热循环 | −40↔+105 °C × 1000 | 10 | 无泄漏，RF 性能不变 |
| 油浸 (1000 h) | HV46/HEES/HFC | 10 | 重量变化 < 0.5 % |
| 振动 + 压力 | 50 g + 350 bar 同时 | 10 | 无泄漏 |
| RF S11 | VNA 测量 | 30 | < −20 dB |

## 7. 关键 FEA 工作量

- ANSYS Mechanical：蓝宝石窗 + Kovar 环 + 钢体的三维结构
- 加载工况：350 bar 静、700 bar 静、压力波动 (0→350)、热应力
- 输出：应力分布、变形、接触压力、疲劳寿命预估
- 估算工时：2 周（含网格优化与多工况）

## 8. 失效模式与对策 (FMEA 节选)

| 失效模式 | 严重度 (1-10) | 频度 | 探测 | RPN | 对策 |
|---|---|---|---|---|---|
| 蓝宝石窗破裂 | 10 | 1 | 5 | 50 | 100 % 压测 + 应力余量 13× |

| 端盖螺纹疲劳 | 8 | 2 | 6 | 96 | 安装力矩 + 螺纹胶 |

## 9. 与系统的接口

- **机械**：M22×1.5 / M27×2 / G3/4 三种螺纹接口端盖，蓝宝石窗居中
- **电气**：SMA 同轴 (玻璃-金属密封) 从端盖背面引入 PCB
- **现场更换**：拧下传感器整体即可，**承压窗集成在传感器侧**，不
  与缸体永久结合。这就是 IRM "现场 2 min 更换不污染油液" 的物理
  基础
